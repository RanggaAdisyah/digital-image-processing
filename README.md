\# Digital Image Processing



Collection of Python implementations of core digital image processing

techniques, built for the Digital Image Processing course.



| No | Topic | Folder |

|----|-------|--------|

| 1 | Image load \& save | load gambar |

| 2 | Grayscale conversion | grayscale |

| ... | ... | ... |



\## Requirements

Python 3, Pillow, OpenCV, NumPy, Matplotlib



\## How to run

Open a topic folder and run its script, e.g.:

cd Biner

python biner.py
